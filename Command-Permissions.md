# Commands by Group

Choose the page matching your role. Each higher role inherits lower-role access
unless a permission is world-specific or explicitly denied.

| Group | Command reference | Important scope |
| --- | --- | --- |
| Regular (`default`) | [Regular User Commands](User-Commands.md) | Baseline access in permitted worlds |
| VIP (`vip`) | [VIP Commands](VIP-Commands.md) | Inherits regular; adds kit, portal, and Residence profile |
| Builder (`builder`) | [Builder Commands](Builder-Commands.md) | Most extra permissions only in `bigflatness2` |
| Staff (`staff`) | [Staff Commands](Staff-Commands.md) | Inherits lower groups; moderation and support tools |
| Admin (`admin`) | [Administrator Commands](Admin-Commands.md) | Broad wildcard access; separate from staff |

For command ownership and upstream documentation, see the
[Active Plugin Directory](Plugins.md). The live `/help`, `/jobs help`,
`/res help`, and permission system remain authoritative.
