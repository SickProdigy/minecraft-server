# VIP Commands

VIP inherits every [regular user command](User-Commands.md). The LuckPerms `vip`
group currently adds the following access.

## CMI additions

| Access | Usage |
| --- | --- |
| Diamond kit | Open the server's kit interface or use the live kit syntax to claim `diamond-kit`, subject to its cooldown. |
| Flatness portal | Use the CMI portal named `flatness`, where that portal is available. |

See [CMI](Plugin-Guides/CMI.md). The permission nodes are
`cmi.kit.diamond-kit` and `cmi.command.portal.flatness`.

## Residence VIP profile

VIP uses the Residence `VIP` profile:

- 15 Residences
- 10 physical areas per Residence
- 100×100 horizontal maximum
- 320-block vertical maximum
- subzones up to depth 3
- custom enter and leave messages
- buying, selling, renting, and leasing features

VIP uses the same Residence commands as regular users; its limits and options are
larger. Run `/res limits` for live values and see
[Residence](Plugin-Guides/Residence.md).
