# Server Features

This summarizes player-facing systems confirmed by the current server and plugin
configuration. Features can change or be temporarily disabled during maintenance.

## Java and Bedrock cross-play

The Paper server includes Geyser and Floodgate for Java/Bedrock cross-play.
ViaVersion and ViaBackwards provide additional client-version compatibility. The
exact versions able to connect can change after updates.

## Economy and jobs

Vault and CMI provide the shared economy. Jobs Reborn rewards supported activities
with money, points, and experience. Use `/jobs` and `/balance` to get started.

## Land protection

Residence protects builds and controls access with flags. Players can select
land, create claims, add trusted players, set teleport points, and manage detailed
permissions. Start with [Creating a Residence](Residences/Creating-Residences.md).

## Worlds and navigation

My_Worlds manages worlds and portals. CMI supplies spawn, homes, warps, signs,
holograms, and other navigation features. Available destinations can depend on
rank; the signs and menus at spawn are the live list.

## Community and convenience

- DiscordSRV connects supported Minecraft and Discord community features.
- Dynmap supplies a browser world map when enabled.
- ChatEmojis adds supported emoji shortcuts to chat.
- `/playtimerewards` shows play-time rewards.
- `/discord`, `/website`, and `/donate` show approved links.

AuthMe, FastLogin, Floodgate, ProtocolLib, ViaVersion, and ViaBackwards support
account access and compatibility. Follow login instructions shown in game and
never share passwords or recovery information.
