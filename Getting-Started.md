# Getting Started

## 1. Open help and rules

```text
/help
/rules
```

The help menu links to staff support, land protection, your balance, the rules,
and Discord. Use `/helpop <message>` when you need staff assistance.

## 2. Visit spawn and set a home

Use `/spawn` to return to the main area, where signs, holograms, shops, and
portals explain available destinations. `/home` opens or uses your available home
destination. Home limits and some portals can depend on rank.

## 3. Join a job and earn money

```text
/jobs
/balance
```

`/jobs` shows available actions. Configured jobs include Brewer, Builder, Crafter,
Digger, Enchanter, Explorer, Farmer, Fisherman, Hunter, Miner, Weaponsmith, and
Woodcutter. Jobs can award money, points, and experience for related activities.

Do not exploit unintended farms, prices, or economy bugs. Ask staff if a method
appears unbalanced.

## 4. Protect your home

```text
/res help
/res tool
/res auto MyHome
/res info
/res show
```

Protect a build before storing valuables. For a carefully sized claim, follow the
[Residence creation guide](Residences/Creating-Residences.md).

## 5. Share access carefully

```text
/res padd PlayerName
/res pdel PlayerName
/res info
```

Only add players you trust. Review `/res info` after making changes and remove
access when it is no longer needed.

## 6. Find the community

`/discord`, `/website`, and `/donate` show the current approved community and
support links. `/playtimerewards` shows rewards available for playing.
