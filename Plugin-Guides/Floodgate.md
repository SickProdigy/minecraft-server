# Floodgate

**Purpose:** Supplies Bedrock player identity and account integration for Geyser.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

It has no ordinary player command workflow in McEcon. Administrative tooling is not granted to regular, VIP, builder, or staff groups.
