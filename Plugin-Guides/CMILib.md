# CMILib

**Purpose:** Shared library for CMI, Residence, and Jobs.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

Its declared `/cmil` command is an administrative library/configuration command. It is not granted to regular, VIP, builder, or staff groups.
