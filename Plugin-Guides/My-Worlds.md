# My_Worlds

**Purpose:** Manages loaded worlds, portals, and world travel.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

Normal players use server portals rather than management commands. Builder has context-specific teleport/rejoin access for `bigflatness2` and `world1`. Admin has `myworlds.*`.
