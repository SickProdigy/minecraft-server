# WorldEdit

**Purpose:** Provides selections, bulk world editing, clipboards, brushes, generation, history, and navigation.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

Builder receives broad WorldEdit access only in `bigflatness2`, with super-pickaxe explicitly denied. Staff inherits that contextual builder access. Admin has `worldedit.*`. See [Builder Commands](../Builder-Commands.md) for allowed categories and common syntax.
