# AuthMe

**Purpose:** Account authentication and recovery.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

Regular users can use `/login`, `/logout`, `/register`, `/unregister`, `/changepassword`, `/email`, `/totp`, `/captcha`, `/verification`, `/premium`, and `/freemium` when applicable. Admin has `authme.admin.*`; staff does not. Never share passwords, email codes, TOTP secrets, or recovery codes.
