# Vault

**Purpose:** Bridges CMI economy and permissions to other plugins.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

Players do not interact with Vault directly. `/vault-info` and `/vault-convert` are administrative/diagnostic commands; Vault admin permission belongs to admin.
