# PlaceholderAPI

**Purpose:** Lets plugins share dynamic values used in messages, menus, holograms, and formatting.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

It has no player-facing McEcon workflow. `/placeholderapi` (often `/papi`) is administrative expansion and diagnostic tooling and is not granted to regular, VIP, builder, or staff.
