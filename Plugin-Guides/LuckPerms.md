# LuckPerms

**Purpose:** Controls groups, inheritance, contexts, and permission nodes.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

There are no LuckPerms management commands for regular, VIP, builder, or staff. Admin has `/luckperms` wildcard access plus editor, search, sync, and reload configuration nodes. Permission changes should be reviewed for inheritance and world context before applying.
