# Residence

**Purpose:** Provides land claims, flags, access control, markets, banks, subzones, and claim teleportation.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

Regular users receive extensive owner commands; see [Residence Commands](../Residences/Commands.md) and [Creating a Residence](../Residences/Creating-Residences.md). VIP uses larger limits. Builder receives bypass/unlimited nodes in `bigflatness2`. Staff has Residence admin/bypass/reload. Full administration remains with admin.
