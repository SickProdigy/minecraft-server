# ChatEmojis

**Purpose:** Replaces supported chat shortcuts with emoji.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

The plugin declares `/emoji`. Chat replacement can also occur without a command. No extra VIP, builder, or staff permission is configured.
