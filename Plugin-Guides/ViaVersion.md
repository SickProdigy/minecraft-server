# ViaVersion

**Purpose:** Allows supported newer Java clients to connect and reports protocol compatibility.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

Players do not need commands. `/viaversion` (alias `/viaver`) management and diagnostic actions are not granted to regular, VIP, builder, or staff.
