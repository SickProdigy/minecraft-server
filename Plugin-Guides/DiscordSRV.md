# DiscordSRV

**Purpose:** Connects supported Discord and Minecraft features.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

Regular users have `/discord` plus link, linked-status, and unlink permissions. VIP, builder, and staff inherit those actions. `discordsrv.admin` belongs to admin only.
