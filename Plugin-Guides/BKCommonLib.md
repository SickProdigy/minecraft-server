# BKCommonLib

**Purpose:** Shared library required by My_Worlds.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

It has no declared player command and grants no McEcon role permissions. Players normally interact with My_Worlds or CMI instead.
