# Geyser-Spigot

**Purpose:** Lets Bedrock clients connect through the Java server.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

Players use it by connecting; no normal command is required. `/geyser help` is operational tooling and is not part of the documented regular/VIP/builder/staff command set.
