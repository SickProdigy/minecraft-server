# CMI

**Purpose:** Core player commands, homes, economy, teleport requests, kits, rewards, portals, custom text, and moderation.

**Loaded version:** See the current [Active Plugin Directory](../Plugins.md).

## McEcon access

Regular commands are listed in [Regular User Commands](../User-Commands.md). VIP adds `diamond-kit` and the `flatness` portal. Staff adds moderation, inspection, teleport, give, repair, vanish, and support tools. Admin has CMI wildcard access. `/help` is the live public menu.
