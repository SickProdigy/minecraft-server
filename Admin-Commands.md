# Administrator Commands

The LuckPerms `admin` group is separate from staff and has broad wildcard access:
CMI, LuckPerms, AuthMe administration, Jobs administration, Residence
administration, My_Worlds, WorldEdit, DiscordSRV administration, Vault
administration, and Minecraft administration.

Because wildcard access covers destructive and security-sensitive operations,
this page does not attempt to turn every admin command into a casual checklist.
Use each plugin's guide and upstream documentation, back up first, and verify the
exact target before database, world, permission, authentication, or mass-edit
operations.
